# 🛠️ UserManagement Module For Laravel

A modular User Management package for Laravel, providing user CRUD, roles & permissions (via Spatie), authentication helpers, and advanced logging for actions and exceptions.

> 🔗 Repository: [github.com/Taskio/user-management](https://github.com/Taskio/user-management)

---

## ✨ Features

- ✅ User CRUD (Create, Read, Update, Delete)
- ✅ Role & Permission management with Spatie Laravel Permission
- ✅ Soft delete and restore functionality

---

## 🚀 Installation

In your Laravel project's `composer.json`, add the following:

```json
"repositories": [
    {
        "type": "vcs",
        "url": "https://github.com/Taskio/user-management"
    }
]
"require": {
    "taskio/user-management": "*"
}
```

Then run:

```bash
composer update
```
